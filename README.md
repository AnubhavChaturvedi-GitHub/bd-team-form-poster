# Banner Maker: Create Branded Social Banners from a Form

> Fill in a short form and get a branded LinkedIn or social banner instantly. React and Vite app with live preview, consistent brand templates and one-click PNG export. No design tool needed.

## What it does

Producing on-brand banners usually means opening a design tool and hoping everyone uses the right template. This app removes that: the template is fixed in code, the user only fills in the fields that change, and the export is always correctly sized and on brand.

## Features

- **Form-driven**: type the details, the banner updates live
- **Locked brand template**: fonts, colours and layout stay consistent every time
- **Live preview**: see the exact output while editing
- **One-click export**: download a ready-to-post PNG
- **Correct dimensions**: sized for LinkedIn and social feeds
- **Zero design skill needed**: anyone on the team can produce a correct banner

## Getting started

### Prerequisites

Node.js 18 or newer.

### Installation

```bash
git clone https://github.com/AnubhavChaturvedi-GitHub/bd-team-form-poster.git
cd bd-team-form-poster
npm install
npm run dev
```

### Build and deploy

```bash
npm run build
```

A `netlify.toml` is included, so connecting the repository to Netlify deploys it with no further configuration. The static output in `dist/` also works on Vercel, Cloudflare Pages or GitHub Pages.

## Usage

1. Open the app.
2. Fill in the banner fields.
3. Check the live preview.
4. Click export and download the PNG.

## Customising the template

Base artwork lives in the `Banner Template` folder, and layout and styling live in `src/`. Change those to rebrand the generator for a different team.

## Tech stack

React, Vite, Canvas API, ESLint, Netlify.
